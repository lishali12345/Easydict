# ME-Dict 安装与首次使用

适用于 Apple Silicon（M 系列芯片），macOS 13.0 或更新版本。
此定制版与官方 Easydict 使用不同应用名称和 Bundle ID，可以共存。

## 安装

1. 打开发布者提供的 DMG，将 ME-Dict 拖到 Applications（应用程序）。
2. 从「应用程序」启动 ME-Dict，不要直接在 DMG 内长期运行。
3. 首次运行时确认 macOS 的打开提示。

正式包经过 Developer ID 签名和 Apple 公证。如系统仍报告损坏或无法验证开发者，
请联系发布者核对下载文件和 SHA256SUMS.txt，不要关闭 Gatekeeper 或删除隔离属性。

## 配置自己的翻译服务

安装包不包含发布者的个人服务设置或登录凭据。

1. 在「设置 → 翻译服务」中启用可用服务，按该服务要求填写自己的接口地址、模型和密钥，
   或完成服务提供方要求的登录。
2. 在「设置 → 高级 → 翻译并替换」选择翻译和润色服务，配置目标语言及顺序。
3. 润色需要服务支持相应能力；不可选的服务不适用于润色。

`127.0.0.1` / `localhost` 始终表示当前这台电脑；只有你自己运行了对应服务时才使用此地址。
外部 API 的费用和配额取决于你自己的账号。

## 授权与快捷键

- 翻译并替换、润色并替换需要在「系统设置 → 隐私与安全性 → 辅助功能」授权 ME-Dict。
  如果没有条目，通过“＋”添加「应用程序」中的 ME-Dict。
- 截图 OCR 按需授予屏幕录制权限；系统提示控制其他应用时，按所用功能批准自动化权限。
- 签名、公证不代替隐私授权。无需为普通翻译开启完全磁盘访问权限。
- 在设置中确认翻译、润色及目标语言的快捷键，与官方 Easydict 同时运行时避免重复绑定。
- 候选窗口内，Command+1～9 替换对应译文，Option+1～9 复制对应译文；关闭保留原文。

第一次可在 TextEdit 中选中一段草稿验证，然后在实际聊天软件的输入框中尝试，先不要发送。
部分应用可能不支持直接替换，届时可使用候选窗口的复制功能再自行粘贴。

## 更新与反馈

退出 ME-Dict 后，将新版拖入「应用程序」覆盖旧 ME-Dict。不要覆盖官方 Easydict。
同一分发身份的正常更新会保留个人配置；更改签名身份或系统权限状态可能需要再次授权。
首次从开发签名版切换到分发签名版也可能需要重新授权。

反馈问题时提供 ME-Dict 版本、macOS 版本、所在应用和复现步骤，不提供 API 密钥或密码。

构建依赖及锁定版本位于源码中的 Podfile.lock、Package.resolved 和相关构建文档。
实际版本、构建号、源码 commit、团队、校验和见随 DMG 提供的 manifest.json。

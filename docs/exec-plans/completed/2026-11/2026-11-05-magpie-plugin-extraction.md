## 背景

MeeTar 翻译插件已在本机启用，但源码仍由 Easydict 仓库管理。用户要求迁到独立的 `magpie-plugins` 父目录，并创建对应工程和独立会话便于后续迭代。

## 目标与范围

- 目标结果：插件在独立工程的 `meetar-translation/` 下维护，Magpie 使用新位置加载；个人配置和记录继续沿用。
- 允许修改路径：原 `integrations/magpie-meetar-translation/`、相关迁移说明与 history/plan；用户指定的新独立目录和 Magpie 中对应插件条目的路径。
- 同任务 history：`docs/histories/2026-11/2026-11-05-magpie-plugin-extraction.md`
- 用户限制：不更改翻译行为，不影响 ME-Dict 和官方 Easydict；保留现有术语和记录。
- 非目标：新翻译功能、远端仓库、推送或分发。
- 验收标准：源码内容一致；配置仅有一个新位置的启用条目；原有记录仍在；真实代理请求继续注入并单次入库；新工程与会话关联正确目录。

## 工作计划

1. 记录当前源码、插件配置、术语和记录基线。
2. 建立独立父目录与 Git 仓库，复制插件并调整文档路径，补充接手说明。
3. 备份后原子替换 Magpie 既有条目的路径，验证加载、翻译和记录。
4. 删除 Easydict 中旧源码，保留迁移指引并更新历史文档链接。
5. 独立审查、完成两边本地提交，创建 Codex 工程和独立会话。

## 风险与决策

- 不直接从新目录执行 install，以免旧、新路径同时启用造成双重注入与重复记录。
- 先复制并核验新目录，成功切换后再删除旧源码；保留本地备份用于回退。
- 个人数据目录不移动、不复制入仓库；来源排除和术语规则保持原样。
- 独立工程不复制无关的 macOS 构建规则或 ME-Dict 历史，只记录必要来源与交接信息。

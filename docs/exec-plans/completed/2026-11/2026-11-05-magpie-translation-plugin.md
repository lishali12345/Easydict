## 背景

ME-Dict 和沉浸式翻译使用 Magpie 的 `group/translate` 本机代理。需要统一 MeeTar 业务术语和自然表达，并留存请求及结果供旁路分析。

## 目标与范围

- 目标结果：提供本机可用的 Magpie 插件、可编辑术语列表及可查询导出的翻译记录。
- 允许修改路径：`integrations/magpie-meetar-translation/`、相关使用说明、同任务 plan/history；接入本机 Magpie 的插件配置和独立数据目录。
- 同任务 history：`docs/histories/2026-11/2026-11-05-magpie-translation-plugin.md`
- 用户限制：先在本机运行；仅作用于翻译入口；保持原文完整；不影响官方 Easydict 和现有其他模型调用。
- 非目标：自动客服、自动生成并应用政策、分发插件、重构或重新安装 ME-Dict。
- 验收标准：ME-Dict 与沉浸式翻译的实际请求得到术语约束；原始请求、添加规则后的请求、结果和规则版本能够关联查询；非目标服务入口和官方 Easydict 的调用不采集、不注入。

## 工作计划

1. 核对当前 Magpie 的 hooks 契约、本机加载和回退方式。
2. 实现术语/场景配置、请求注入、SQLite 记录及查询导出入口。
3. 限定 `group/translate`，备份相关本机配置并接入插件。
4. 分别以 ME-Dict、沉浸式翻译验证真实翻译及完整记录，并检查英文和非英文目标语言。
5. 使用 review 技能独立审查，修复有效问题，补充使用说明和 history，归档计划并本地提交。

## 风险与决策

- 使用 Bun 异步 hooks；原始请求与注入后请求分开保存，不做原文字符串替换。
- 中文术语以 `Host`、`Agency` 为英文语义基准，允许必要语法变化；其他语言在同一次请求内以英文语义为参考。
- 保留客户端目标语言、流式开关及输出结构；不主动调用额外模型或自动改变政策。
- hook 完成通知为尽力投递；缺失或不完整捕获如实标记，不承诺零丢失。
- 配置与记录放本机独立目录，权限限制为当前用户；不记录认证 headers，不提交真实翻译内容。
- 本任务未授权新增测试文件；通过静态检查和用户要求的实际客户端验证验收。
